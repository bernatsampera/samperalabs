02 / Inspect a mood

Choose a label.

What this cannot tell us

The decision to inspect.

One review can suggest more than one mood. This sketch links each label to the words that support it. Select a label to keep the source and the reason in view.

These labels and reasons are fixed examples. This page does not run an AI model. A real review can be unclear. The source still needs to be checked before a label is treated as a fact about a gym.

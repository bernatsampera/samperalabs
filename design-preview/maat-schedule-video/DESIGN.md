# Schedule import video

## Direction

Show one fictional class moving from a timetable image to editable text, JSON, and a class in MAAT.
Use a silent demonstration with short explanations. Hold each explanation while its action happens.
This is an illustrated product demonstration, not a recording of a live OCR run.

## Colors

Use the SamperaLabs site palette from ../../src/assets/styles/tokens.css.
Canvas: #F2F2F4. Paper: #FFFFFF. Ink: #14141A. Secondary text: #5F5F67. Rule: #E2E2E6.
Blue #1D5BFF marks the current action, selected class, or correction.

## Typography

Use the existing Geist font for explanations and interface text.
Use monospace only for extracted text and JSON.
Use 64px explanations, 30px data, and 24px supporting labels on a 1920 by 1080 canvas.
Keep the existing calm weights. Do not force heavy display typography.

## Motion

Use short crossfades between related views and precise movement within a view.
Let field entries, extraction, correction, and conversion explain the work.
Keep enough still time to read. Do not add ambient motion or animated decoration.
Use the same fictional class throughout: Monday, BJJ Fundamentals, 18:00 to 19:00.

## Do not use

- Narration or music.
- A logo intro, slogan, or generic closing call to action.
- Large text that repeats a smaller explanation in the same scene.
- Flashy transitions, gradients, particles, or decorative card grids.
- Unlabelled staged errors or claims of verified live model behavior.

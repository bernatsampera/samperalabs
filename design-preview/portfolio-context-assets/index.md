# Portfolio context illustrations

These illustrations were generated with the built-in image generation tool for the local portfolio preview.

- [context.png](context.png): An iceberg with a large submerged mass represents context behind a visible question.
- [structure.png](structure.png): A card catalogue with one open drawer represents structured information and retrieval.
- [maintaining.png](maintaining.png): A bonsai tree, pruning scissors, and a cut twig represent maintaining information.
- [prompts.json](prompts.json): The complete prompts and tool mode used for the three generated images.

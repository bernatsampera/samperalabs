# Editorial rules

Bernat owns each article's idea, opinions, and final text.
AI helps with structure, language, evidence, and images.
Start an article only on request. Publication needs a separate instruction.
Intended post workflow: Bernat creates posts about the things he is doing, in nicely written language, with images like highagency.
Keep preparation local unless Bernat requests a remote draft.

Current request: show a feature on a project and explain it. Bernat does not want this post creation to happen automatically.

The rule Bernat refers to should be added in src/docs/ for creating articles.
Bernat disagrees with the decision made on the sections; the article should go more on the decision.

Use presentation-only help for an existing draft unless editing is requested.
Do not invent personal experiences, feelings, motives, quotes, or measured results.
Use a clear reader benefit and a concrete example supported by evidence.
Explain unfamiliar system terms. Use short active sentences and plain hyphens.
All articles get a manual review by Bernat, with AI help.
Review the rendered article on phone and desktop before publication.
Bernat wants criteria on how to present information for readers, with everything of very high quality.

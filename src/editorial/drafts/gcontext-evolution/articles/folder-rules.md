A folder can tell an agent where to read. It also needs to explain what belongs there when the agent has new information to save.

The experiments tested explicit folder rules and versioned structures. The goal was to make the context grow according to its purpose, rather than collect a new note for every fact.

## Placement and restructuring are different decisions

New information can lead to several actions:

| Situation | Possible change |
| --- | --- |
| The file already states the fact | Keep the file as it is |
| The fact changes an existing rule | Update the relevant passage |
| The fact belongs in the folder but has no place yet | Add content or a file |
| The folder no longer serves its purpose | Review its structure |

These are examples of the decisions the rules must support. They are not a claim that the system always makes the right choice.

The September experiments examined file changes over time. A final tree alone could hide repeated information or awkward intermediate decisions.

## Give the folder a purpose

Rules based on one example can fit that example and fail on the next project. Each context needed to express its purpose.

That included deciding when several pieces belong in one file. A universal rule that makes one file per fact would prevent some useful structures.

The experiments explored both placement and later restructuring. Real conversation records became important because small artificial examples did not expose all the ways that context could grow badly.

# Optional post images

Use an image only when it helps explain the post. Keep the post readable without it.

## Image brief

Record these details before you make or choose an image:

- Idea: the point from the post that the image must explain.
- Contrast: the two states or steps that the reader must see.
- Placement: the heading or paragraph that comes before the image.
- Caption: the short explanation below the image. Mark example data as illustrative.
- Alt text: the information a reader needs when they cannot see the image.

Prefer clear shapes, readable labels, and neutral colors. Do not add invented results or claims. Check the source for each factual label.

## Add and review

1. Make or choose the image manually.
2. Upload it with the existing image control in the post editor.
3. Use the existing Markdown image format when you edit Markdown: `![Useful alt text](image-url)`.
4. Add the caption as a short paragraph below the image.
5. Preview the post on a phone and a desktop screen.
6. Check the labels, alt text, caption, and image size.
7. Publish only after the normal content review.

This workflow is optional. It adds no image generation service or automatic publishing step.
